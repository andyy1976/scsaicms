# 内容数字员工工具 - 配置清单

## 一、必须配置项（核心功能）

### 1. AI API 密钥配置

**位置**：`Web/Lib/Action/ContentemployeeAction.class.php`

**需要配置的API**：

| API | 用途 | 获取方式 |
|-----|------|---------|
| `DEEPSEEK_API_KEY` | DeepSeek AI（主模型） | https://platform.deepseek.com/ |
| `TENCENT_SECRET_ID` | 腾讯云（图像生成） | https://console.cloud.tencent.com/ |
| `TENCENT_SECRET_KEY` | 腾讯云密钥 | 同上 |

**配置方式**：
```php
// 方式1：环境变量（推荐）
$apiKey = getenv('DEEPSEEK_API_KEY');

// 方式2：直接配置（不推荐）
private $deepseekApiKey = 'sk-xxxxxxxxxxxxxxxx';
```

## 四、服务器配置

### 1. PHP环境

**要求**：
- PHP >= 7.2
- 扩展：curl, json, mbstring, pdo_mysql

### 2. Nginx/Apache配置

**Nginx示例**：
```nginx
server {
    listen 80;
    server_name www.sciotai.com;
    root /www/wwwroot/cms;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?s=$uri&$args;
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        include fastcgi.conf;
    }
}
```

### 3. 定时任务（可选）

```crontab
# 每小时采集热点
0 * * * * cd /www/wwwroot/cms/workbuddy-claw-wechat-publisher && npm run hotspot

# 每天生成日报
0 8 * * * cd /www/wwwroot/cms/workbuddy-claw-wechat-publisher && npm run daily
```

## 七、常见问题

### Q1: 页面可以访问，但AI功能不工作？
**A**: 需要配置 `DEEPSEEK_API_KEY`，获取地址：https://platform.deepseek.com/

### Q2: 如何获取微信公众号API？
**A**: 登录微信公众平台 → 开发 → 基本配置 → 获取AppID和AppSecret

### Q3: 热点采集为什么没有数据？
**A**: 需要配置微博/知乎的Cookie，或者等待定时任务执行

### Q4: 如何对接企业知识库？
**A**: 联系我们进行定制开发，或使用老板智能体企业版
