# 企业内容自动化服务 - 销售话术模板

## 一、开场白（3种场景）

### 场景1：电话/微信冷启动
```
您好，我是超云智能的[姓名]。我们最近帮一家[同行业]企业做了一个产品内容自动化方案，
把他们每次新品发布写说明书的时间从4天缩短到10分钟。不知道贵司在产品文档制作这块，
现在是怎么处理的？有没有遇到人手不够、更新慢的问题？
```

### 场景2：社群/朋友圈触达
```
【制造业老板看过来】
每次新品发布都要从头写说明书、宣传册、销售话术？
我们帮一家设备企业搭建了AI自动化系统：
✅ 输入产品参数，自动生成说明书
✅ 每月自动产出3篇公众号推文
✅ 销售话术库自动更新
原来需要4天的工作，现在10分钟搞定。
想了解怎么做到的？私信我发你案例详情。
```

### 场景3：老客户转介绍
```
[老客户名]推荐我联系您。他说你们最近在扩充产品线，可能需要内容方面的支持。
我们给他做过一套产品内容自动化系统，效果不错，所以想看看能不能也帮到您。
方便的话，我发个案例给您参考？
```

## 二、需求挖掘（5个关键问题）

```
1. "贵司现在产品说明书/技术文档是怎么制作的？是专人负责还是外包？"
   → 判断：人力成本、外包费用、制作周期

2. "每次新品发布，从准备资料到完成文档，大概需要多长时间？"
   → 判断：痛点强度、ROI计算基数

3. "公众号/小红书这些平台，现在更新频率怎么样？内容来源是？"
   → 判断：内容运营能力、是否需要内容生成

4. "销售团队拿到的产品资料，客户能看懂吗？有没有反馈说太技术化？"
   → 判断：技术翻译需求、销售转化痛点

5. "如果有一套系统能自动生成这些内容，您觉得每月能省下多少人力？"
   → 判断：预算空间、决策动力
```

## 三、方案介绍（针对制造业/设备企业）

### 标准版话术
```
根据您刚才说的情况，我给您推荐我们的【产品内容自动化助手】。

这套系统主要解决三个问题：
1. 新品说明书制作慢——我们对接您的产品数据库，输入型号和参数，
   自动生成标准说明书+用户易懂版+销售话术，原来4天的工作10分钟搞定。

2. 公众号内容匮乏——系统每月自动抓取行业热点，生成3篇符合您企业风格的文章，
   排版好直接能发，不用再为选题发愁。

3. 销售资料不统一——系统自动维护销售话术库，每周更新常见客户问题及答案，
   新销售也能快速上手。

我们有一家做工业机器人的客户，用了这套系统后，每月省下1个文案的人力成本，
公众号阅读量还提升了40%，因为内容更专业、更新更及时了。

您看这个方案，能解决您现在遇到的问题吗？
```

### 进阶版话术（针对有定制需求的客户）
```
您这个需求比较特殊，标准方案可能不完全匹配。不过我们支持定制开发。

比如您提到要对接ERP系统、要生成多语言版本、要发布到海外平台——这些我们都能做。

我建议这样：我们先做一个免费诊断，我派技术同事上门看看您现有的系统和流程，
然后出一份定制方案和报价。您看下周哪个时间方便？
```

## 四、报价策略

### 基础套餐（适合中小企业）
```
我们有两个方案供您选择：

【方案A：标准版】
- 项目搭建费：2.5万元（含知识库搭建、3条自动化工作流、30天技术支持）
- 月度维护费：5000元/月（含持续优化、内容生成、故障处理）
- 适合：产品线在20个以内、公众号更新频率中等的企业

【方案B：专业版】
- 项目搭建费：4万元（含定制开发、多平台对接、培训）
- 月度维护费：8000元/月
- 适合：产品线多、需要多平台发布、有定制需求的企业

按您刚才说的情况，方案A应该够用了。您看要不要我先发个详细的服务清单给您？
```

### ROI计算话术
```
我帮您算笔账：

您现在一个文案月薪1万，每年12万。
如果用我们的系统，每月省下他50%的工作时间，相当于省6万/年。
我们的服务费是：项目费2.5万 + 月费5000×12=6万，第一年总投入8.5万。
但您还获得了：公众号内容质量提升、销售资料更专业、新品发布更快...

第二年起，只需要月费6万，净省6万以上。

这还没算内容质量提升带来的销售转化提升。您觉得这个投入产出比怎么样？
```

## 五、异议处理

### 异议1："太贵了"
```
我理解您的顾虑。不过您想一下：
- 如果您招一个文案，月薪至少8000，一年10万，还不包括培训、社保、管理成本。
- 如果外包，一份说明书至少2000，一年做20份就是4万，还不包括公众号内容。
- 我们这套系统，第一年8.5万，之后每年6万，而且内容质量稳定、永不离职。

您也可以先试用一个月，看看效果再决定要不要长期合作。
```

### 异议2："AI生成的内容质量怎么样"
```
这个担心很正常。我们的系统不是简单的ChatGPT套壳，而是：
1. 接入了您的企业知识库，生成的内容是基于您的产品参数、技术文档、历史案例。
2. 有专业的"去AI味"处理，让文字更自然、更像人写的。
3. 每条内容生成后，我们会人工审核，确保质量。

您可以看看我们给[某客户]做的案例，这是他们公众号最近的文章，您觉得质量如何？
```

### 异议3："我们已经有文案了"
```
那太好了！我们的系统不是要替代您的文案，而是让他从重复劳动中解放出来。

比如写产品说明书这种工作，用我们的系统10分钟搞定，您的文案可以把时间花在
更有价值的事情上——比如策划专题、做视频、研究竞品。

相当于您花5000元/月，给文案配了一个"超级助手"，他的产出效率能翻倍。
```

### 异议4："需要对接我们的系统，会不会很麻烦"
```
这个您不用担心。我们有标准对接流程：
1. 您提供产品数据（Excel、ERP导出、或者产品目录都行）
2. 我们技术团队负责对接，一般3-5个工作日完成
3. 对接完成后，我们会培训您的同事怎么使用

整个过程您只需要配合提供数据，其他都是我们来搞。
```

### 异议5："能不能先免费试用"
```
可以！我们有两种试用方式：

方式1：单次体验——您发我一个产品参数，我免费帮您生成一份说明书，您看看效果。

方式2：月度试用——您付第一个月的月费5000元，我们帮您搭建简化版系统，
   试用一个月，满意再付项目费，不满意月费退还。

您倾向哪种方式？
```

## 六、促成成交

### 软性促成
```
那这样，我先把服务清单和案例发给您，您跟团队商量一下。
有任何问题随时找我，微信电话都行。
如果确定要做，我们最快下周就能开始搭建。
```

### 硬性促成
```
您看要不要这周就把合同签了？我们最近排期比较紧，再晚可能要等两周才能开工。
而且现在签约，我还能帮您申请一个优惠：首月月费减半。
```

### 紧迫感促成
```
对了，我们最近在做活动，前5名签约的客户，项目费打8折。
现在还剩2个名额，您如果这周能定下来，就能享受这个优惠。
```

如果满意的话，能不能帮我个忙——您行业里有没有朋友也遇到类似的问题？
如果有的话，能不能帮我引荐一下？成功签约的话，我送您3个月月费。
```

### 老客户激活
```
[老客户名]您好，好久不见！您的系统最近运行得怎么样？
对了，我们最近推出了一个新功能[XX]，对您可能有用，要不要我给您演示一下？
另外，您朋友里有没有需要类似服务的？我们最近在做活动，推荐成功有奖励。
