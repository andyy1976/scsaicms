
# 我用AI搭建了一个全自动公众号文章发布系统

做公众号的朋友，有没有过这种体会？

想日更，但选题就要想半小时，写文章要三小时，排版还要一小时，发到公众号还要调半天格式。一天下来，光发布流程就耗光了所有精力，根本没时间思考内容质量。

## 痛点：公众号运营那点事，说多了都是泪

做过公众号的都懂，一篇文章从 idea 到发布，要走多少流程：

1. **找热点**：得刷微博、刷知乎、刷B站，看看今天大家在聊什么，半小时过去了
2. **想选题**：找到热点还要想角度，能不能写，适合不适合我的受众
3. **写文章**：几千字写下来，两三个小时没了
4. **排版**：markdown转微信格式，要调字号、调行间距、加图片、改标题样式，又是一小时
5. **做封面**：还要找图、做尺寸、导PNG，上传素材库
6. **发布**：最后还要复制粘贴到公众号后台，点一下保存草稿

一套流程走下来，大半天没了。如果只是业余做公众号，根本挤不出这么多时间。

有没有可能，这些事情全让AI做了，我们只需要负责想idea，或者干脆连idea都让AI找？

## 解决方案：全自动公众号文章发布流水线

我基于OpenClaw搭了这么一个工具，叫「WorkBuddy微信公众号发布器」，它能帮你全自动走完整个流程：

### 第一步：自动抓热点，按你的口味过滤

你只需要配置一次关键词：

```json
"keywords": {
  "primary": ["人工智能", "AI", "大模型", "数字化"],
  "secondary": ["互联网", "新能源", "创业"],
  "exclude": ["明星", "娱乐", "八卦"]
}
```

工具每天自动去微博、知乎、B站、小红书抓热点，然后按你的关键词评分，找到最匹配你领域的热点。标题匹配关键词还会双倍加分，精准度比盲抓高很多。

v3.0我还优化了评分算法，标题权重是内容的两倍，不会出现内容提到关键词但其实不相关的情况。

### 第二步：卡兹克风格AI写作，完全没有AI味儿

找到热点之后，直接调用AI生成文章，用的是「数字生命卡兹克」独家写作风格：

> 「有见识的普通人在认真聊一件打动他的事」，讲人话、有温度、有洞见、不端着

严格遵循卡兹克的写作结构：

1. **开头钩子**：80字以内，用一个震惊数据或者画面引发好奇
2. **三个信号**：从现象到本质，层层递进
3. **深度解构**：权力/尊严/关系的深层分析
4. **文明视野**：宏观趋势，三个转身
5. **实用建议**：3条可操作建议，放在蓝绿渐变框里
6. **升华结尾**：金句收尾 + 互动引导

写出来的文章读起来就像真人写的，完全摆脱了那种AI套话味儿。

### 第三步：自动转微信排版，去除所有markdown符号

很多人用markdown写作，复制到公众号一大堆 `#` `**` 符号，还要手动删。这个工具自动帮你转成微信兼容的HTML：

- ✅ 去掉所有markdown标记符号
- ✅ 标题自动加蓝色左边框样式
- ✅ 引用块自动转橙色边框背景框
- ✅ 建议块自动转蓝绿渐变背景
- ✅ 段落自动分段，不会出现一大坨挤在一起

你写的markdown是什么样，转出来微信里就是什么样，完全不用再调。

### 第四步：增强发布 - 自动生成封面和内容配图

v3.0新增了增强发布功能，如果你已经写好了markdown文章，只需要一句话：

```bash
wechat-publisher --enhanced 我的文章.md
```

它会自动帮你：

1. 从文章提取关键词
2. 自动匹配分类
3. 根据标题生成渐变封面图
4. 从关键段落生成3张内容配图
5. 把所有图片上传到公众号素材库
6. 在合适的位置插入配图
7. 最后发布到草稿箱

全程真的不用你碰一下，喝杯咖啡回来文章已经在草稿箱里了。

### 第五步：一键发布到公众号草稿箱

所有工序完成后，直接调用微信公众号官方API，发布到你的公众号草稿箱。你打开公众号后台就能看到，直接点预览或者群发就行。

## 怎么用？三步上手

### 第一步：安装

如果你用OpenClaw，直接安装插件：

```bash
openclaw plugins install workbuddy-claw-wechat-publisher
```

npm安装也可以：

```bash
npm install -g workbuddy-claw-wechat-publisher
```

### 第二步：配置

运行初始化：

```bash
/wx-setup
```

然后填入三个东西：
1. 公众号AppID和AppSecret（在公众号后台「设置与开发」里）
2. 默认封面图MediaID（上传一张到素材库就能拿到）
3. AI API Key（推荐用DeepSeek，性价比高）

配置一次，终身可用。

### 第三步：发布

自动热点发布：

```bash
/wx-publish
```

然后坐等收文章就行，写完直接在草稿箱里。

发布你自己写的markdown：

```bash
/wx-enhanced 你的文章.md
```

## 为什么做这个工具？

我一直在想，AI时代，个人创作者的生产力工具应该是什么样？

答案就是：**把重复的全自动化，把创造的留给人**。

1. 定方向（你关注什么领域）
2. 做判断（发不发，改一改）

这才是正确的分工——AI干它擅长的，人干人擅长的。
